# すずたるみLP

`index.html` をブラウザで開くと表示できます。インストールやビルドは不要です。

- 1ページ目に `aseets/すずLP_1_re.png`、続いて `すずLP_2.png` 〜 `すずLP_9.png` を順番に横スライドで表示します。
- スワイプ、左右ボタン、キーボードの左右キーで切り替えられます。
- `すずLP_CTA_re.png` はスライドの外側の共通フッターに配置し、全ページで下部に表示します。
- 共通フッターの空白部分に `すずLP_CTAボタン.png` を重ね、3.4秒ごとに光が流れるアニメーションを付けています。動きを減らす端末設定では停止します。
- `すずLP_CTAバッジ.png` は価格の右上に、CTAの上端から少しはみ出す形で全ページに表示します。
- 画像は切り抜かず、縦横比を維持して表示します。PCでは中央寄せ、スマートフォンでは画面サイズに合わせます。
- 10ページ目に「ご予約・お問い合わせ」を配置しています。CTAから移動し、フォーム内を縦にスクロールして入力できます。
- フォームの項目・質問・選択肢・注意書きは参照LPに合わせています。予約日は参照元と同じ端末日付の3日後以降、日曜・月曜・祝日を除きます（祝日一覧は参照元と同じ2026〜2027年分。以降は更新が必要です）。
- 予約フォームは既存LPと同じWeb3Forms設定で送信し、成功時は既存の `/tarumi-thanks/` に移動します。GTMも既存と同じコンテナを設定済みです。実際の送信・メール受信・サンクスページ遷移の確認はご担当者が実施してください。

フォーム参照元: https://suzu-kuma.github.io/01-uemabuta-tarumi.html#booking

フォルダ名 `aseets` は提供時の名称をそのまま使用しています。

ローカルサーバーで確認する場合:

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

ブラウザで http://127.0.0.1:4173/ を開きます。

5ページ目は `aseets/すずLP_5_re.png` を使用しています。

6ページ目は `aseets/すずLP_6_re.png` を使用しています。

9ページ目は `aseets/すずLP_9_re.png` を使用しています。

公開先は既存の `/tarumi-thanks/` が利用できるホストを使用してください。ローカルプレビューのルートにはサンクスページを作成していません。

3ページ目は `aseets/すずLP_3_re.png` を使用しています。

第2・第3希望は初期状態で非表示です。直前の希望日・時間を両方選ぶと次の希望欄が表示されます。非表示欄は入力値を保持して送信対象から除外します。
